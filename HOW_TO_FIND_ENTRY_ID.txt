🔍 FINDING YOUR ENTRY ID - STEP BY STEP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━


STEP 1: Open Your Google Form
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Copy this URL and open in browser:
https://docs.google.com/forms/d/e/1FAIpQLScBVVjWsUoxV2ysXVgJBfcZ8_XKD2v6cScqRKXbEDo2zbv-Dw/viewform

This shows your form in "view" mode (not edit mode).


STEP 2: Open Developer Tools
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

WINDOWS: Press F12
MAC: Press Cmd + Option + I
CHROME MENU: ... → More tools → Developer tools

You should see a panel at bottom/side with code.


STEP 3: Go to Console Tab
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Look for tabs at top of Developer Tools:
  Elements | Console | Sources | ...
  
Click: Console


STEP 4: Paste This Code
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Copy this entire code block:

┌──────────────────────────────────────────────────────────────────┐
│ const emailInput = document.querySelector('input[type="email"]'); │
│ if (emailInput && emailInput.name) {                             │
│   console.log('Your Entry ID is: ' + emailInput.name);           │
│ } else {                                                          │
│   console.log('Could not find email field. Try manual method.');  │
│ }                                                                 │
└──────────────────────────────────────────────────────────────────┘

In console, type or paste the code above.
Press: Enter


STEP 5: See the Result
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Console will show something like:

  Your Entry ID is: entry.987654321
  
Copy this entire thing: entry.987654321


STEP 6: Update index.html
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Open index.html in text editor (VS Code, Sublime, Notepad++)

Search for: entry.1234567890

You'll find this line around line 280:

┌──────────────────────────────────────────────────────────────────┐
│ formData.append('entry.1234567890', email);                      │
└──────────────────────────────────────────────────────────────────┘

REPLACE entry.1234567890 with YOUR entry ID.

Example - if your entry ID is entry.987654321:

┌──────────────────────────────────────────────────────────────────┐
│ formData.append('entry.987654321', email);                       │
└──────────────────────────────────────────────────────────────────┘

Save the file.

🆘 IF IT DOESN'T WORK
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Problem: "Could not find email field"
Solution: Your form might not have an email field, or it's structured differently
  → Add an email field to your Google Form
  → Or use a text field for email

Problem: Nothing appears in Google Form responses
Solution: Entry ID might be wrong
  → Double-check the entry ID (no typos)
  → Make sure you saved index.html
  → Refresh and try again

Problem: Can't find the line in index.html
Solution: Search more carefully
  → Use Ctrl+F (Find) to search for "entry.1234567890"
  → There's only one instance


✨ MANUAL METHOD (If Console Code Doesn't Work)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Open Google Form in browser
2. Right-click on the email field
3. Click "Inspect" or "Inspect Element"
4. Look at the HTML code for: name="entry.XXXXXXX"
5. Copy the entry ID
6. Update index.html
