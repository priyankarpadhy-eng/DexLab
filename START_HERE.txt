📊 HOW EMAILS GET SAVED TO EXCEL
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

User submits email on website
         ↓
Frontend sends to backend
         ↓
Backend validates & checks Excel
         ↓
If valid, adds new row to waitlist.xlsx
         ↓
File saved to disk automatically
         ↓
Success! Email now in Excel forever ✅

No setup needed! It just works!

🆘 COMMON ISSUES & FIXES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

"npm: command not found"
  → Install Node.js from https://nodejs.org/

"npm install" takes forever
  → Normal! First install downloads packages (~5 min)
  → Subsequent runs are instant

Server won't start on port 3000
  → Maybe port 3000 is in use
  → Edit server.js line: PORT = 3001 (or any number)

Form doesn't save emails
  → Did you run "npm start"? (Check terminal)
  → Try refreshing page
  → Check browser console for errors

Excel file won't open
  → Make sure npm start ran successfully
  → Try submitting another email
  → waitlist.xlsx should appear in this folder
