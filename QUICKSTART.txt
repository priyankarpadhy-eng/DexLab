⚡ OPTION 1: RUN WITH BACKEND (SAVES TO EXCEL)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: Install Node.js (if not already installed)
  → Download from: https://nodejs.org/
  → Choose LTS version

STEP 2: Open PowerShell in this folder & run:
  
  npm install
  npm start

STEP 3: Open browser & visit:
  
  http://localhost:3000

STEP 4: Fill in email & click "Join Waitlist"
  → Email saved to: waitlist.xlsx (in this folder)
  → Timestamp recorded automatically
  → Status marked as "Pending"

THAT'S IT! Users can now submit emails ✅

🚀 DEPLOY TO INTERNET (ONE-CLICK)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

RECOMMENDED: Railway (Easiest - takes 2 minutes)

1. Go to: https://railway.app
2. Sign up (free with GitHub)
3. Click "New Project" → "Deploy from GitHub"
4. Connect your repo (push this folder to GitHub first)
5. Railway auto-detects Node.js app
6. Click "Deploy" → Done! 🎉

Your site now live at: https://your-app.railway.app
Emails auto-save to Excel in the cloud!

❓ FAQ

Q: Where is my Excel file?
A: waitlist.xlsx in this folder. Open with Excel or Google Sheets.

Q: Can I use Google Sheets instead?
A: Yes! See SETUP_EXCEL.md for Google Apps Script setup.

Q: How do I run this on my domain?
A: Deploy to Railway/Heroku, change your domain DNS to point there.

Q: Can I add more fields (name, phone, etc.)?
A: Yes! Edit form in index.html and columns in server.js

Q: Is this mobile-friendly?
A: 100% responsive! Test on phone/tablet.

Q: Can it handle 100k+ signups?
A: Yes! Excel files can handle millions of rows.
