STEP 1: Find Your Email Field Entry ID

Open your Google Form in a new tab:
https://docs.google.com/forms/d/e/1FAIpQLScBVVjWsUoxV2ysXVgJBfcZ8_XKD2v6cScqRKXbEDo2zbv-Dw/viewform

Press F12 (open Developer Tools)
Go to Console tab
Paste this code and press Enter:

┌─────────────────────────────────────────────────────────────────┐
│ // Find email field entry ID                                    │
│ const emailInput = document.querySelector('input[type="email"]');
│ if (emailInput) {                                               │
│   console.log('Email Entry ID: ' + emailInput.name);            │
│ }                                                                │
└─────────────────────────────────────────────────────────────────┘

COPY the entry ID you see (example: entry.123456789)


STEP 2: Update index.html

Open index.html in a text editor (VS Code, Sublime, Notepad++)

Find this line (around line 280):
  formData.append('entry.1234567890', email);

Replace 'entry.1234567890' with YOUR entry ID:
  formData.append('entry.123456789', email);

Save the file


STEP 3: Test It!

Run:  npm start

Visit: http://localhost:3000

Submit a test email

Check your Google Form responses:
https://docs.google.com/forms/d/e/1FAIpQLScBVVjWsUoxV2ysXVgJBfcZ8_XKD2v6cScqRKXbEDo2zbv-Dw/edit
→ Click "Responses" tab
→ You should see your test email! ✅

❓ TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

"I can't find the entry ID"
  → Make sure you're on the VIEWFORM page (not edit)
  → Look for the email input field specifically
  → Or try the alternative method in GOOGLE_FORM_SETUP.md

"Form submits but nothing appears in Google Form"
  → Check entry ID is correct (no typos)
  → Make sure you saved index.html
  → Try submitting again

"Getting CORS error"
  → This is normal! Google blocks CORS but submission still works
  → Check your Google Form responses to confirm

"Console shows errors"
  → F12 → Console tab
  → Look for error message
  → Make sure entry ID matches exactly
